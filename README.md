# 🧠 Iris Flower Classification using K-Nearest Neighbors (KNN)

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![scikit-learn](https://img.shields.io/badge/scikit--learn-1.2%2B-orange)](https://scikit-learn.org/)

This project implements a complete **supervised machine learning pipeline** to classify Iris flowers into one of three species: **Setosa**, **Versicolor**, or **Virginica**, based on four morphological measurements (sepal length, sepal width, petal length, petal width). The classification model is built using the **K‑Nearest Neighbors (KNN)** algorithm with hyperparameter tuning via **GridSearchCV** and 5‑fold cross‑validation.

## 📌 Overview

- **Goal** – Build a robust classifier that can predict the species of an Iris flower with high accuracy.
- **Dataset** – Classic Iris dataset (150 samples, 4 features, 3 classes), included in `scikit-learn`.
- **Algorithm** – K‑Nearest Neighbors (KNN), a simple yet powerful non‑parametric method.
- **Key steps** – Data exploration, visualisation, train/test split, feature scaling, model training, hyperparameter tuning, evaluation, and prediction on new data.
- **Best performance** – Achieved **100% test accuracy** (on the held‑out 20% split) with `k = 3` after tuning.

## 🧪 Methodology – Supervised Learning Pipeline

1. **Load Data** – Iris dataset from `sklearn.datasets`.
2. **Explore Data** – Check shape, statistics, class balance.
3. **Visualise** – Pairplot, correlation heatmap, feature distributions.
4. **Train‑Test Split** – 80% training, 20% testing, stratified by default.
5. **Feature Scaling** – `StandardScaler` (mean=0, variance=1) – crucial for KNN.
6. **Choose Algorithm** – KNN with initial `k = 5`.
7. **Train Model** – `model.fit(X_train_scaled, y_train)`.
8. **Predict** – `model.predict(X_test_scaled)`.
9. **Evaluate** – Accuracy, confusion matrix, classification report.
10. **Hyperparameter Tuning** – Test `k` values from 1 to 20 using `GridSearchCV` with 5‑fold CV.
11. **Visualise Results** – Decision boundary (2D projection), confusion matrix heatmap.
12. **Predict New Samples** – Function to classify user‑provided measurements.
